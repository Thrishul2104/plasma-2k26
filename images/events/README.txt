Optional photo for each event card. Put files in THIS folder, named after the event
(lowercase, hyphens). Use .jpg (or .jpeg / .png / .webp):

  robo-race.jpg
  line-follower.jpg
  robo-soccer.jpg
  sumo-war.jpg
  rc-car-race.jpg
  hardware-hackathon.jpg
  paper-presentation.jpg

Tips: landscape photo, about 800 x 450 px, under 300 KB each.
If a photo is missing, the card simply shows its icon instead.
For a NEW event added later, name the file after the event the same way
(e.g. event "Drone Dash" -> drone-dash.jpg).
